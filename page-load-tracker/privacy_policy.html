Privacy Policy

Page Load Tracker

Last updated: August 2026

Page Load Tracker ("the extension") is a Chrome browser extension that measures how long a website takes to load. It shows the total load time as a badge in the toolbar and a per-stage breakdown (DNS, connection, request, response, DOM parsing, and more) in its popup.

Data we collect

Page Load Tracker does not collect, transmit, sell, or share any user data with the developer or with any third party. All processing happens entirely on the user's own device, inside their browser.

The extension reads only the performance timing data your browser already records for the current page via the built-in Navigation Timing API. This timing data:

  • Is stored only temporarily on the user's device, in the browser's local extension storage
  • Is automatically deleted when the browser tab it belongs to is closed
  • Is never sent to any external server, API, or third party
  • Is never accessed, viewed, or logged by the developer

Permissions and why they're needed

storage

Saves the measured load timing for each open tab locally, so the popup can display the breakdown for the currently active tab. Data is removed when the tab closes.

Content script access (all sites)

Runs on every page the user visits solely to read that page's own Navigation Timing data. It never reads, modifies, or sends any page content.

Data sharing

We do not sell, rent, or transfer user data to third parties. We do not use any data for advertising, credit, or lending purposes. We do not use data for any purpose unrelated to the extension's single purpose of measuring and displaying page load time.
