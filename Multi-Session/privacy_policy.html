Privacy Policy

Multi-Session

Last updated: August 2026

Multi-Session ("the extension") is a Chrome browser extension that lets users open isolated browser tabs, each with its own separate cookie space, so they can be logged into multiple accounts on the same website at the same time.

Data we collect

Multi-Session does not collect, transmit, sell, or share any user data with the developer or with any third party. All processing happens entirely on the user's own device, inside their browser.

The extension reads and rewrites cookie data (including authentication/session cookies) as part of its core function of isolating login sessions between browser tabs. This cookie data:

  • Is stored only in the browser's local, temporary session storage
  • Is automatically and permanently deleted when the browser is closed
  • Is never sent to any external server, API, or third party
  • Is never accessed, viewed, or logged by the developer

Permissions and why they're needed

storage

Keeps track locally of which browser tab belongs to which isolated session, and which cookies belong to it.

tabs

Detects when a new isolated tab is opened or closed, so its session data can be created or cleaned up.

webRequest

Used in read-only mode to observe Set-Cookie response headers on isolated tabs, so their cookies can be tracked separately from the browser's shared cookie jar.

declarativeNetRequest

Isolates cookies per tab by removing the outgoing Cookie header by default, restoring only that tab's own cookies, and preventing incoming Set-Cookie headers from writing into the shared browser cookie jar.

Host permissions (all sites)

Required because the user may choose to open an isolated session for any website; the extension cannot predict in advance which sites will be used.

Data sharing

We do not sell, rent, or transfer user data to third parties. We do not use any data for advertising, credit, or lending purposes. We do not use data for any purpose unrelated to the extension's single purpose of isolating login sessions between tabs.
